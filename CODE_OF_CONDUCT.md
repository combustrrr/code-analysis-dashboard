# Code of Conduct

## Our commitment

We are committed to providing a welcoming, safe, and inclusive project for
everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and evidence rather than attacking people.
- Accept feedback gracefully and acknowledge mistakes.
- Protect private information, credentials, and vulnerability details.
- Respect maintainers' decisions about project scope and security boundaries.

Harassment, discrimination, threats, deliberate disruption, and publication of
another person's private information are not acceptable.

## Enforcement

For ordinary conduct concerns, contact the repository owner privately through
their GitHub profile. Do not use a public issue when a report contains private
information. Security vulnerabilities must be reported using the process in
[SECURITY.md](SECURITY.md).

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behavior violates this policy. Reports will be
reviewed as promptly and confidentially as practical.

## Scope

This policy applies in repository spaces and when someone is officially
representing this project in another public space.
